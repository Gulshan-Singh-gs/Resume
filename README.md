# Gulshan Singh - Resume Repository

This repository contains the source code for my professional, ATS-optimized, single-column resume. 

## Why This Format?
- **ATS Compliant:** Parses perfectly into automated HR systems. No columns, graphics, or tables to break the parsers.
- **Maintainability:** Built with raw HTML/CSS. No complex dependencies, no proprietary software needed.
- **Print-Ready:** The CSS is specifically constrained to `max-width: 850px` to ensure it prints cleanly to a standard A4/Letter PDF format.

## How to Edit
1. Open `index.html` in any text editor (VS Code, Sublime, Notepad++).
2. Look for the HTML comments `` to find exactly where to plug in new skills, projects, or grades.
3. Save the file and refresh your browser to see changes instantly.

## How to Export to PDF (For Job Applications)
You should **never** submit an HTML file as a job application. Always send a PDF.
1. Open the `index.html` file in Google Chrome or Microsoft Edge.
2. Press `Ctrl + P` (or right-click -> Print).
3. Set the Destination to **"Save as PDF"**.
4. In settings, set Margins to **"None"** or **"Minimum"**.
5. Uncheck **"Headers and Footers"** to remove the date and file path from the printed page.
6. Click Save.
